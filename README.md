# EffiSol Solar Quotation Generator ☀️

Professional Solar Proposal Generator web application for **EffiSol Energy Solutions Pvt. Ltd.** (Visakhapatnam, Andhra Pradesh).

🌐 **Live Web Application:** [https://kalavalajohnlinnu-ui.github.io/EFFISOL-SOLAR-QUOTATION-GENERATOR/](https://kalavalajohnlinnu-ui.github.io/EFFISOL-SOLAR-QUOTATION-GENERATOR/)

---

## ⚡ Supported Proposal Types

1. **On-Grid Solar PV System**
   - High-efficiency Topcon / Monoperc bifacial modules
   - Government subsidy calculation
   - 25-Year cumulative bill savings analysis
   - Full 7-Page proposal with portfolio & commercial terms

2. **Off-Grid Solar PV System**
   - Appliance-level design load calculation (Sunny vs. Non-Sunny hours)
   - LiFePO4 battery storage sizing & depth-of-discharge analysis
   - Optional Backup Hours load table toggle
   - Optional 2-page project portfolio toggle (5 to 8 page dynamic output)

3. **Smart Hybrid Solar PV System**
   - Solar PV + Inverter + Lithium Battery storage
   - 25-Year diesel generator fuel savings analysis
   - Dynamic 7-page / 5-page proposal generation
   - Integrated commercial offer & technical terms

---

## 🛠️ Features & Technology

- **100% Client-Side:** Generates pixel-perfect PDFs directly in the browser using `pdf-lib` without any backend server.
- **Local Storage:** Automatic auto-save and restore of customer input data.
- **Dark Premium UI:** Built with glassmorphism, responsive grid layout, and real-time calculation previews.
